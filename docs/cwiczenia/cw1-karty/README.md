# Ćwiczenie 1: kartki ról w wersji elektronicznej

Na sali kartki są na papierze. Jeśli papieru nie ma, otwórz tylko swoją kartkę (podgląd Markdown w VS Code: Ctrl+Shift+V):

- osoba A: [karta-a.md](karta-a.md)
- osoba B: [karta-b.md](karta-b.md)
- „deweloper” w danej rundzie: [karta-zastrzezen.md](karta-zastrzezen.md)

Swoje liczby i rachunek kosztu wpisz w kopii kartki albo od razu w szkicu ADR (szablon [../../szablony/adr.md](../../szablony/adr.md)).
