# Po szkoleniu: od czego zacząć każde działanie

Plan wdrożenia z bloku 4 (szablon: [`docs/szablony/plan-wdrozenia.md`](szablony/plan-wdrozenia.md)) ma osiem działań sekcji testów oraz listy dla deweloperów i IT. Przy każdym działaniu niżej jest plik albo gałąź repo demo, od której zaczynasz w swoim projekcie, i polecenie, którym sprawdzisz wzorzec na repo demo.

Pliki z gałęzi rozwiązań otwierasz na GitHubie (linki) albo lokalnie bez przełączania gałęzi:

```powershell
git fetch origin
git show origin/solution/2a:packages/test-core/src/fixtures.ts
```
